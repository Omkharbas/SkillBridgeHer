# 🌟 SkillBridge Her

A modern and empowering platform designed to help women explore **STEM careers**, identify their skills, access learning resources, discover opportunities, and build personalized career roadmaps.

SkillBridge Her connects users with the right resources, opportunities, mentorship, and career guidance in one place. The platform also includes an **interactive map** to help users discover nearby opportunities, learning centers, events, and resources.

## 🚀 Features

* **👤 Personalized Profile**: Users can create a profile based on their skills, interests, education, and career goals.

* **🧠 AI Career Guidance**: Provides personalized career suggestions and recommendations based on user interests and skills.

* **📊 Skill Assessment**: Helps users identify their strengths, weaknesses, and skill gaps.

* **🛣️ Personalized Career Roadmap**: Generates a structured learning and career path with clear goals and milestones.

* **📚 Learning Resources**: Provides access to relevant courses, resources, and skill-building materials.

* **💼 Opportunities**: Helps users discover jobs, internships, workshops, and other career opportunities.

* **🗺️ Interactive Opportunity Map**: Allows users to explore nearby opportunities, learning centers, events, workshops, and useful resources based on location.

* **📈 Progress Tracking**: Enables users to track their learning journey and career development.

* **🤝 Community & Mentorship**: Connects users with mentors, communities, and other learners for guidance and support.

* **📱 Responsive Design**: Works smoothly across Desktop, Tablet, and Mobile devices.

## 🛠️ Tech Stack

* **Frontend**: HTML, CSS, JavaScript / React
* **Backend**: Node.js, Express.js
* **Database**: MongoDB
* **AI Integration**: AI-powered career guidance
* **Maps**: Interactive map and location-based opportunity discovery

## ⚙️ How to Run

## 🎯 Problem We Aim to Solve

Many women face challenges in accessing the right career guidance, learning resources, mentorship, and opportunities in STEM and other professional fields.

**SkillBridge Her** aims to bridge this gap by providing a centralized platform where users can:

* Discover their skills and interests
* Receive personalized career guidance
* Follow structured learning roadmaps
* Find relevant opportunities
* Explore nearby resources through an interactive map
* Connect with mentors and communities
